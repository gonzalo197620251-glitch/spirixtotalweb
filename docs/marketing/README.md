# 🚀 Kit de Crecimiento y Marketing — SpirixTotal
## Guías, Prompts y Estrategias para Escalar a Nivel Internacional

Este directorio contiene todo el material estructurado para transformar las métricas de Google Search Console, activar Instagram/Facebook y conseguir clientes en el exterior para torneos de artes marciales.

---

### 📂 Contenido del Kit:

1. **[01_GUIONES_REELS_TIKTOK.md](01_GUIONES_REELS_TIKTOK.md)**
   * 5 guiones con gancho, texto en pantalla, desarrollo y llamados a la acción para videos verticales de 20 a 30 segundos.
   * Diseñados para maestros, árbitros y directores de torneo.

2. **[02_PLANTILLAS_OUTBOUND_WHATSAPP_IG.md](02_PLANTILLAS_OUTBOUND_WHATSAPP_IG.md)**
   * Mensajes listos para copiar y pegar en WhatsApp y MD de Instagram.
   * Plantillas para torneos recién anunciados, presidentes de asociación, torneos urgentes y versión en portugués para Brasil.

3. **[03_ESTRATEGIA_GRUPOS_FACEBOOK.md](03_ESTRATEGIA_GRUPOS_FACEBOOK.md)**
   * Estrategia de publicaciones sin spam en comunidades masivas de artes marciales en Sudamérica y México.
   * Modelos de posts de debate y casos de estudio que provocan preguntas y pedidos de cotización.

4. **[04_CONFIGURACION_DOMINIO_Y_SEARCH_CONSOLE.md](04_CONFIGURACION_DOMINIO_Y_SEARCH_CONSOLE.md)**
   * Checklist paso a paso para conectar `spirixtotal.com` a Netlify.
   * Cómo dar de alta la propiedad internacional en Google Search Console y enviar el `sitemap.xml`.
